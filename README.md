# Benjamin Korir Portfolio

A personal portfolio website built to showcase my work, projects, and online profiles as a frontend-focused developer.

## Live Project

https://myth254.github.io/frontend-portfolio/

## Overview

This project is a responsive single-page portfolio created with HTML and CSS. It highlights:

- A brief introduction about me
- Social links to GitHub, LinkedIn, and Credly
- A gallery of featured projects
- Clean, modern styling for a professional portfolio presentation

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- GitHub Pages for deployment

## Project Structure

- `index.html` — main portfolio page structure
- `style.css` — page styling and responsive layout
- `images/` — project screenshots, profile image, and icons

## Run Locally

You can view the site locally by opening `index.html` in a browser, or by serving the project with a simple local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
